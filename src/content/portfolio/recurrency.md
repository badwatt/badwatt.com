Recurrency is a self-hosted subscription, expense and debt tracker built in Rust with Axum, PostgreSQL and a Dioxus frontend. It treats every expense as a commitment and answers the three questions a spreadsheet does not: what has to be transferred this month, what is still pending today and whether a subscription is worth keeping. It ships as one all-in-one Docker image that serves the web UI and the API on the same port.
